# ClassManager

A desktop application for student and class management built with **Java** and **JavaFX**.

## 📌 Project Overview

This project is a standalone management system designed to handle student registration, group organization, and class data within a single integrated environment.

## 🛠️ Tech Stack

* **Language:** Java 21 (LTS)
* **GUI Framework:** JavaFX
* **Build Tool:** Maven
* **Database:** SQLite (Local storage)

## 🏗️ Key Features

* **Student Management:** Create, read, and list student records.
* **Group Organization:** Tools to manage and view group members.
* **Local Persistence:** Data is stored locally in an SQLite database.
* **Modern UI:** Clean interface built with JavaFX FXML.
